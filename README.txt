JANPRADESH 24 NEWS - WEBSITE STARTER

Files:
- index.html: public news homepage
- admin.html: local news entry form
- style.css: responsive red/white news design
- site.js: browser-side news storage
- assets/janpradesh24-logo.png: cropped Janpradesh 24 branding from the previously shared channel graphic

IMPORTANT LIMITATION:
This is a working front-end starter. The admin form stores stories only in the same browser/device using localStorage. It does NOT publish stories to the public internet or sync across devices. To make public posting work, the site needs free hosting plus a shared database/CMS connection. Do not enter private information into this demo.

To preview: open index.html in a browser. On some phones, opening local HTML from a ZIP may require extracting the ZIP first.
